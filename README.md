# OnlyWorlds docs

The source of [onlyworlds.github.io](https://onlyworlds.github.io): the OnlyWorlds schema, API, SDKs and AI tools. Built with [Starlight](https://starlight.astro.build) and deployed to GitHub Pages by `.github/workflows/pages.yml`.

The Jekyll site this replaced is kept whole on the `jekyll` branch and the `jekyll-final` tag.

## Work on it

```bash
npm ci
npm run build     # astro build, then scripts/postbuild.mjs
npm run verify    # the URL gate (scripts/verify-urls.mjs) on dist/
node scripts/serve.mjs   # dist/ on http://localhost:4321/, resolved the way GitHub Pages resolves it
```

Pages are Markdown in `src/content/docs/`, at the URL they are served from. The sidebar (in `astro.config.mjs`) is independent of the folders.

## Old URLs are part of the contract

keel's error responses link to `/api/errors#<code>`, the LLM guide lives at `/assets/ow_llm_guide.txt`, and tools, READMEs and AI chats link to old paths. `contract/urls.tsv` lists every one, with where it is linked from:

- **load-bearing** rows must answer 200 with the real page, on this host. Never a redirect stub: agents read the stub, not its target.
- **floor** rows are the error codes keel links to; each must be an id on `/api/errors/`.
- **page** rows are old pages nothing outside links to; a stub redirect is enough if one moves.

Two gates read that file: `npm run verify` on every build (CI and the deploy), and the live check in Hangar (`fleet/docs_contract.py`) on the deployed site. A page keeps its path; to move one that the contract lists, change the contract first.

`build.format: 'file'` writes `page.html`, which Pages serves as both `/page` and `/page.html` (the old site's two forms). `scripts/postbuild.mjs` moves section pages (`<dir>/index.md`) back to `<dir>/index.html`, so `/docs/x` keeps its same-host 301 to `/docs/x/`.

## Element pages

The field tables on the 22 element pages are generated by `scripts/gen_elements.py` from [schema-dist](https://github.com/OnlyWorlds/schema-dist), through schema-dist's own walk (imported from the checkout after it is verified against its `MANIFEST.json`, never copied). Hand-written prose stays above the marker line; everything below it is rewritten. The deploy runs the generator every 4 hours, so the site follows the schema without commits.

```bash
python scripts/gen_elements.py --dist ../schema-dist          # rewrite
python scripts/gen_elements.py --dist ../schema-dist --check  # exit 1 if a page is behind
```
